
# AI API Resilience Evaluation

### An Empirical Evaluation of Lightweight Resilience Strategies for AI-Powered Web APIs Under Controlled Model-Service Failures

AI-powered applications increasingly depend on external model services to deliver intelligent functionality. However, these dependencies introduce reliability challenges, including service timeouts, temporary unavailability, and unpredictable response delays.

**AI API Resilience Evaluation** is an empirical research project that investigates how lightweight resilience strategies can improve the reliability of AI-powered web APIs under controlled model-service failures.

The project implements a research prototype and evaluates strategies such as timeout handling, retries, circuit breakers, and fallback mechanisms through controlled experiments. Their effectiveness is assessed using reliability and performance metrics, including request success rate, error rate, response time, and recovery behaviour.

The objective is to identify the strengths, limitations, and trade-offs of different resilience strategies and provide evidence-based insights into building more reliable AI-powered web applications.
